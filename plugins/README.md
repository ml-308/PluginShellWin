# 插件目录

本宿主扫描此目录下的一级子目录，每个子目录必须是「文件夹 + `manifest.json`」，
且目录名等于清单里的 `id`。

初始为空 —— 这正是"未安装插件时只显示「请安装插件」"的验收状态。

## 插件从哪里来

1. **py 版已装的插件**：只要 `%LOCALAPPDATA%\PluginShell\plugins` 里有插件，
   本程序会自动复用，不需要重新安装。
2. **任意文件夹形式插件**：通过「插件管理… → 安装文件夹…」安装。
3. **安装包里的示例插件**：安装时勾选「Install sample plugins」即可放进本目录。

插件协议为 1.0，与 PluginShell（py 版）完全一致，插件源码无需任何修改。
